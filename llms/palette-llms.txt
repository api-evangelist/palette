# Palette

> Palette (Palette HQ) is a sales commission and incentive compensation management platform that automates the calculation, tracking, and payout of sales commissions in real time for revenue operations and finance teams. Founded 2020 in Paris (Y Combinator S21), backed by Bain Capital Ventures. SOC 2 Type II compliant.

Palette has no publicly documented developer API. The product connects to source systems (CRM, billing, data warehouses) through one-click managed connectors rather than a public REST API. Palette monitors a component it calls "API" on its own status page, and its documentation host historically redirected to the application login — so an API exists, but its reference is customer-only and no machine-readable contract (OpenAPI, GraphQL SDL, AsyncAPI, MCP manifest, agent card) is published at any location.

As probed on 2026-08-13, the product-plane hosts were unreachable: doc.palettehq.com returns CloudFront 502 "Failed to contact the origin", app.palettehq.com is a CNAME to a CloudFront distribution with no address record, and api.palettehq.com is a CNAME to an Elastic Beanstalk environment that is NXDOMAIN. The Webflow marketing site, blog and company email remain live.
